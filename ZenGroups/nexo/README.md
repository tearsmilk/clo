# Значки групп для Nexo

`make_badges.py` рисует 9-px бейджи в стиле `badges.yml` (badge_admin / badge_player): `badge_moder`, `badge_media`,
`badge_vipplus`, `badge_vip` → `pack/assets/zengroups/textures/font/`, глифы — `glyphs/zengroups.yml`
(`font: minecraft:default`, char назначает Nexo). Значок Ферма+ — старый длинный (44x9), в roles.yml он в prefix после значка группы через `&f`, пробел внутри `premium.badge`.
`roles.proposed.yml` — TakuCore roles.yml без собственных значков ролей: значок берётся из `%zengroups_*_prefix%`.
