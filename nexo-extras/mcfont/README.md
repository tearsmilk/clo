# mcfont.py — рендер текста шрифтом Minecraft для превью

Нужны файлы из клиента 1.21.11 (не хранятся в репо): `assets/minecraft/font/include/default.json` и
`assets/minecraft/textures/font/{ascii,accented,nonlatin_european}.png`, распакованные рядом со скриптом
(`unzip client.jar 'assets/minecraft/textures/font/*' 'assets/minecraft/font/*'`; ссылка на jar — в piston-meta).
