# ZenQuests

Система квестов для Paper / Leaf 1.21.11.

- Авторы: **nakuZen**
- Сайт: https://hoka.ink

## Сборка (macOS, VSCode, JDK 25)

```bash
chmod +x gradlew      # один раз, если после распаковки нет прав на запуск
./gradlew build
```

Готовый плагин: `build/libs/ZenQuests-1.6.0.jar` → кинуть в `plugins/` сервера.
В VSCode: открыть папку `ZenQuests`, поставить Extension Pack for Java + Gradle for Java
(предложит сам), сборка — вкладка Gradle → `build → build`.
Байткод собирается под Java 21 (минимум Paper 1.21.11), работает и на Java 25.

## Возможности


- **Ежедневные**: каждый день в 00:00 игроку выпадают `daily.count` случайных квестов из списка.
- **Еженедельные**: каждый понедельник в 00:00 — `weekly.count` случайных.
- **Сезонные**: все квесты сезона доступны, пока идут его даты (`start`–`end`).
- **Сюжетные**: цепочки шагов, следующий шаг открывается после награды за предыдущий.

Меню: `/квесты` (или `/quests`, `/квест`) — 6 рядов: профиль игрока, категории с индикаторами
(есть награды / в процессе / всё выполнено), страницы, звуки. В «Сюжетных» — список историй,
клик по истории показывает все её шаги: пройденные, текущий и закрытые. Цвета рамок, иконки
и все тексты — в `config.yml → menu` и `gui`.

Из коробки: 38+10 ежедневных, 26+8 еженедельных, 2 сезона (12 и 8 квестов),
3 сюжетные цепочки (в т.ч. «Хроники Тихой долины» — 11 глав).
Фермерский тултип: `config.yml → menu.tooltip-style: "zenquests:farm"` — предметы меню получают
свой стиль подсказки; картинки (`assets/zenquests/textures/gui/sprites/tooltip/farm_*.png`) идут
ресурспаком через Nexo. Без пака ставь `""`, иначе у игроков будет фиолетово-чёрная рамка.

Нарисованные фоны меню: `config.yml → menu.textures.enabled: true` — название окна рисует картинку
176x222 из шрифта `zenquests:menu` (ресурспак через Nexo: `assets/zenquests/font/menu.json` +
`textures/gui/menu/*.png`), стекло рамки не ставится. Без пака ставь `false`.

Если `quests.yml` на сервере уже есть, новые квесты появятся только после его замены. Награды — команды из консоли (`{player}` — ник).
Админ: `/квесты reload`, `/квесты reset <игрок> [daily|weekly|seasonal|story|all]`.

Квесты — в `plugins/ZenQuests/quests.yml` (описание всех полей в начале файла),
настройки и тексты — в `config.yml`, прогресс игроков — в `players/<uuid>.yml`.

## Подписка Ферма+

Подписчик — игрок с правом `zenquests.premium` (имя права меняется в `config.yml → premium.permission`).
Выдавать командой (для опов / `zenquests.admin`, работает и для игроков не в сети, если они уже заходили):

```
/квесты premium give <ник> [срок]   # 30d, 12h, 1w, 1d12h, forever (по умолчанию — навсегда); продлевает текущую
/квесты premium take <ник>          # забрать выданную командой подписку
/квесты premium check <ник>         # сколько осталось
```

Выданные командой подписки хранятся в `plugins/ZenQuests/premium.yml`. Срок виден игроку в меню.

Или донат-плагином / LuckPerms (право работает вместе с командой):

```
/lp user <ник> permission settemp zenquests.premium true 30d
```

Что даёт:
- **доп. ежедневные/еженедельные** — `daily.premium-count` + `daily.premium-quests` (так же для `weekly`), выдаются сверху обычных;
- **сезонные только для подписки** — `premium: true` у квеста сезона;
- **сюжетные цепочки только для подписки** — `premium: true` у цепочки;
- **бонус к награде** — `premium-rewards` у любого квеста, выдаётся вместе с обычной наградой.

Без подписки игрок видит в меню замок «Ещё N заданий с Ферма+» и бонусы серым. Тексты — в `config.yml → premium`.
Купил подписку посреди дня — доп. задания на сегодня появятся сразу.

## TakuFarmers

Нужен TakuFarmers с API 1.0+. Квесты подключаются сами (softdepend), в консоли при старте пишется, какие события найдены.

| Тип | Что | Цель |
|---|---|---|
| CROP_HIT / CROP_HARVEST / CROP_BREAK | удар / собранный урожай / срубленный куст | wheat, carrot, potato, onion, tomato, cucumber |
| COOK | готовка на станции завершена | id станции |
| COOK_ITEM | приготовленное блюдо | предмет или id Nexo |
| MILL | результат жёрнова | предмет или id Nexo |
| FLOUR_SACK | мешок муки | — |
| EARN / SPEND | заработано / потрачено | COINS, GEMS |
| FARM_VISIT | зашёл на свою ферму | — |
| NPC_TALK / DIALOG | клик по NPC / диалог по F | id NPC / id диалога |

Отменённые события не засчитываются. EARN считает любые начисления, в том числе награды за квесты, если они в монетах.

## Засчитать действие из другого плагина

- Командой (из консоли, например в наградах или скриптах):
  `/квесты progress <игрок> <тип> [цель|-] [кол-во]` — `/квесты progress Hoka CROP_HARVEST wheat 3`
- Из кода (softdepend: [ZenQuests]):
  `ink.hoka.zenquests.QuestsAPI.progress(player, "CROP_HARVEST", "wheat", 3);`
