# Hokaria Art Generator

Генератор уютных пиксельных аниме-картинок для Minecraft-сервера Hokaria. Это одна страница `index.html` без сборки и без своего сервера: картинки рисуют внешние сервисы.

## Движки

- **Pollinations**: бесплатно и без регистрации. Качество попроще, в углу водяной знак, без ключа сервис пускает примерно одну картинку за раз (сайт сам ждёт и повторяет).
- **Hugging Face FLUX.1-schnell**: качество выше. Нужен свой бесплатный токен (huggingface.co → Settings → Access Tokens). Токен хранится только в браузере. Бесплатных генераций в месяц немного.

## Как открыть

- Локально: просто открыть `index.html` в браузере.
- В интернете: включить GitHub Pages для репозитория (Settings → Pages → Deploy from a branch → ветка с `index.html`, папка `/ (root)`).
